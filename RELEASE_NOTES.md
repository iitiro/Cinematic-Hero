# Cinematic Hero — Box Office and Narrative Archetypes

Research scripts and data for exploring cinematic hero archetypes, franchise patterns, and box-office change.

- Includes the Ukrainian box-office workbook for 2005–2025 and analytical CSV tables.
- Generates Ukrainian market indicators, title-based archetype coding, and nine figures.
- Provides a separate worldwide analysis script with portable fonts and configurable input/output paths.
- Adds reproducible setup instructions and offline regression checks.

**Data scope:** The worldwide source workbook is not bundled. Archetype coding is a title-level proxy, and revenue values are nominal. Coverage and missing-field limitations are documented in the README.
